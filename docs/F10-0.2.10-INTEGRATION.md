## Design review and direction

Product: a CarPlay connection console for a Samsung phone or a tablet mounted in a right-hand-drive F10. Its job is to choose an iPhone and start or manage the session with a glanceable, reachable connection action.

The prior UI's strongest feature was its large right-side connection button. Its main problems were fixed-height text containers, mixed stock icon styles, a permanently dark theme, seven-column audio controls on narrow screens, and reliance on decor fitting on Android versions that enforce edge-to-edge.

The redesign applies Apple foundations and accessibility guidance to native Android Views; Android navigation, dialogs, permission requests and switches retain their platform behavior. No iOS navigation conventions or blur effects are imposed.

Guidelines read from `.agents/skills/apple-design`:

- `accessibility.md › Vision`: “Support larger text sizes.” Text uses sp and containers grow with content.
- `layout.md › Adaptability`: “Be prepared for text-size changes.” Large text switches the regular layout to one column.
- `layout.md › Visual hierarchy`: “Group related items to clearly express related information or functions.” Phones/hotspot form one group, with session actions beside it.
- `lists-and-tables.md › Content`: “Keep item text succinct so row content is comfortable to read.” Settings retain category navigation and a title/current-value hierarchy.
- `dark-mode.md › Best practices`: “Ensure that your app looks good in both appearance modes.” Native resource variants follow the system setting.
- `typography.md › Ensuring legibility`: “In general, avoid light font weights.” Roboto regular/medium throughout.

### Tokens and layout

Six core roles, with a quieter border, selected-row fill and warning color as auxiliary resources:

| Token | Role | Light | Dark |
| --- | --- | --- | --- |
| background | Canvas | #F2F4F7 | #111820 |
| surface | Content groups | #FFFFFF | #1D2733 |
| text | Main text on surface | #182434 (15.7:1) | #F0F4FA (13.7:1) |
| secondary | Supporting text on surface | #536174 (6.3:1) | #B2C0D1 (8.2:1) |
| accent | Actions and selected text on surface | #235BC3 (6.3:1) | #A6C8FF (8.9:1) |
| on_accent | Primary action text on accent | #FFFFFF (6.3:1) | #102344 (9.2:1) |

Roboto scale: 34 sp page title, 24 sp product/phone headings, 22 sp sections, 18 sp actions/settings, 16 sp body/status, 14 sp secondary setting details. Primary connection uses 28 sp. Normal touch targets are at least 56 dp high; controls wrap vertically at larger text sizes. Safe-area insets explicitly reserve system bars and display cutouts on modern Android.

Layout uses available width, stacking below 650 dp or at font scale 1.6 and above. Compact and short landscape screens omit the repeated page title and hotspot summary. Hotspot details stay one tap away. Compact normal-text layouts use a two-column action group; text above 1.3 uses a single column. Horizontal rows disable baseline alignment to prevent multiline controls from clipping. Short landscape settings use three columns and two rows. The startup surface uses compact typography and a scroll container with safe-area padding; projection hides the entire container. Home and projection keep the display awake while visible.

```text
Compact                    Regular / right-hand-drive
DiPlay       Car home       DiPlay                      Car home
CarPlay                     CarPlay
[ Phones           ]        [ Phones + hotspot ] [ Connect phone ]
[ Connect phone    ]                             [ Audio ][ Wi-Fi ]
[ Audio ][ Wi-Fi   ]                             [ Settings ][ End ]
[ Settings ][ End  ]
```

Signature: the large connection surface closest to the driver. Everything else stays quiet, using one coherent vector icon family. This direction is specific to the mounted receiver and preserves the useful F10 layout. The repeated title is removed on short displays; decorative motion and transparency add no value here and are omitted. Native ripples provide touch and keyboard-focus feedback.
