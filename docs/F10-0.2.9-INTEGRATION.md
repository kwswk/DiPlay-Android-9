# F10 selective 0.2.9 integration

This local `0.2.9-f10-ux` build keeps the right-hand-drive home grid, visible device picker, explicit session teardown, speaker/Bluetooth routing, quick-launch widget, and Android 9 audio/microphone fixes. It incorporates selected upstream changes rather than the entire upstream release.

Included from upstream:

- Day/night configuration polling and preservation of undefined mode (`c1195aa`).
- Audio streams 0–20, legacy navigation-setting migration, and matching channel previews (`56d5651`, `4d3211b`). Vendor channels still depend on device support; automatic routing remains the default.
- Preserve the negotiated video canvas during temporary window shrink/restore, fit video without distortion, and map touch coordinates to visible content (`9d90d06`). A session started in a smaller window reconnects once when the window grows (`7eb4a3f`).
- Leave GPS course empty when direction is unknown (`853edc6`).
- Navigation/song widget (`2f7d911`) with the final 0.2.9 route-expiry and song-clearing fixes. Only the song-state parser is included; BYD dashboard song output is omitted. Settings exposes a pin action alongside the existing quick-launch widget.

Floating maps, additional mirror decoders, public map-sharing services, the Android 11 Home sample, and BYD dashboard music output are omitted for this Samsung Android 9 build.

Validation on 3 October 2026: 310 shared and 99 common regression tests passed, followed by one additional Android 9 RemoteViews rendering/clearing test. Mobile lint and standalone APK build passed. Emulator installation, settings launch, and navigation-widget placement passed. Physical SM-P205 installation is pending because serial `R52N81SZNRF` was absent from ADB during validation; earlier tablet results do not establish validation of this new build.

Source: [upstream 0.2.9 notes](https://github.com/shihabal3amri/DiPlay/blob/v0.2.9/docs/RELEASE-NOTES-0.2.9.md).

## Native interface redesign

Home now separates a visible phone list and hotspot status from the larger right-side connection controls. Pairing, audio output, hotspot details, settings, and disconnect use consistent native touch targets. Paired audio accessories are excluded from the phone list unless already selected.

Settings is organized into Connection setup, Display and performance, Audio routing, Widgets and language, Privacy and permissions, and Help and diagnostics. Detailed choices show a title and current value; nested Back navigation returns to the category or menu. No UI dependencies were added.

Redesign validation: all 101 common tests passed, including Android 9 settings navigation and saved-choice checks. Mobile lint and standalone APK build passed. Home, category menu, and display settings were inspected on the emulator at the SM-P205's 1920×1200 resolution and 320 dpi. Physical installation and live iPhone performance remain pending while the tablet is absent from ADB.
